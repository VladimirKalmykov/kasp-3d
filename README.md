# Walk Viewer Web

Веб-просмотрщик автономных GLB. В комплекте две локации: `demo/location1.glb` и `demo/location2.glb`. Веб-приложение работает по адресу `/demo3d`; параметр `scene` выбирает локацию из `scenes.json`.

## Запуск

Нужен Python 3.9 или новее. Из каталога проекта:

```powershell
python server.py
```

Откройте [http://127.0.0.1:8000/demo3d](http://127.0.0.1:8000/demo3d). Прямая ссылка на первую локацию: [http://127.0.0.1:8000/demo3d?scene=location1](http://127.0.0.1:8000/demo3d?scene=location1). Для доступа с телефона в одной локальной сети запустите `python server.py --host 0.0.0.0`, затем откройте `http://АДРЕС-КОМПЬЮТЕРА:8000/demo3d` (если брандмауэр разрешает входящие подключения). Остановить сервер: Ctrl+C.

Сервер не требует установки пакетов. Three.js **0.186.0** находится в `web/vendor`; лицензия — `web/vendor/LICENSE`. Исходные файлы получены из [официального npm-пакета Three.js](https://www.npmjs.com/package/three/v/0.186.0).

## Управление

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Вращение вокруг якоря | Левая кнопка мыши и перетаскивание | Перетаскивание одним пальцем |
| Приближение / удаление | Колесо или Shift + левая кнопка и перетаскивание вверх / вниз | Щипок двумя пальцами |
| Сдвиг якоря вместе с камерой | WASD: W вверх, S вниз, A влево, D вправо относительно экрана | Движение двумя пальцами |
| Стартовый вид | Кнопка «Сбросить вид» | Кнопка «Сбросить вид» |

На компьютере панель справа показывает якорь, yaw / pitch в градусах и дистанцию. Нажатие на число копирует его. Кнопка снизу копирует фрагмент `scenes.json` с четырьмя полями камеры. Буфер обмена в браузере доступен на `localhost` или по HTTPS. На телефоне панель скрыта.

## Настройка сцен

`scenes.json` читается **при запуске сервера**. Для применения изменений остановите сервер, запустите его снова и обновите страницу в браузере. Локации показываются в порядке, указанном в файле. Каждая запись содержит обязательные `slug`, `title`, `file` и необязательные параметры камеры:

```json
{
  "slug": "location1",
  "title": "Локация 1",
  "file": "demo/location1.glb",
  "anchor": [0, 1.5, 0],
  "distance": 12,
  "yaw": 35,
  "pitch": 20
}
```

`slug` состоит из строчных латинских букв, цифр и дефисов. Файл должен быть `.glb` внутри каталога `demo/`. Параметр URL `scene` принимает только slug из конфига; URL файла модели напрямую указать нельзя. Если координаты и дистанция не заданы, просмотрщик берёт центр габаритов основной glTF-сцены и вычисляет дистанцию для обзора. `yaw` — горизонтальный угол, `pitch` — вертикальный; оба в градусах. Начальные углы без значений в конфиге: 35° и 20°. Движение посетителя не сохраняется. После настройки вида можно скопировать параметры из панели и вручную вставить их в нужную запись.

В `location1.glb` записаны две технические glTF-сцены. Просмотрщик показывает только сцену по умолчанию (`scene: 0`); пункт меню при этом один. В текущих GLB нет источников света и анимаций, поэтому просмотрщик добавляет нейтральное освещение. Цвет может отличаться от рендера Blender. Для новых файлов используйте автономный GLB со встроенными текстурами. Переключение анимации дня и ночи в этой версии не реализовано.

## Публикация

Для публичного HTTPS-адреса запустите сервер на хосте и направьте `/demo3d` и `/demo3d/` на него через обратный прокси. Например, в Nginx:

```nginx
location /demo3d {
    proxy_pass http://127.0.0.1:8000;
}
```

Сервер должен быть доступен только с локального интерфейса за прокси: стандартный запуск уже использует `127.0.0.1`. TLS и имя домена настраиваются в прокси. Внешние CDN не нужны: браузер получает скрипты Three.js с того же сервера.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Проверьте обе сцены в настольном браузере и на телефоне: орбиту, зум, сдвиг якоря, копирование, кнопку сброса, выбор сцены и прямые ссылки. Размер GLB влияет на время первой загрузки: `location1.glb` около 20 МБ, `location2.glb` около 8 МБ.
