# Walk Viewer Web

Веб-просмотрщик автономных GLB. В комплекте две локации: `demo/location1.glb` и `demo/location2-3.glb` (slug `location2`). Приложение работает по адресу `demo3d/`; параметр `scene` выбирает локацию из `scenes.json`.

## Сборка

Нужен Python 3.9 или новее. Из каталога проекта:

```powershell
python scripts/build-static.py
```

Команда создаёт каталог `dist/`, готовый для публикации. Внутри:

- `dist/index.html` — переход в `demo3d/`
- `dist/demo3d/index.html` — приложение
- `dist/demo3d/scenes.json` — публичный список сцен (без путей к файлам)
- `dist/demo3d/models/<slug>.glb` — модели
- `dist/demo3d/static/` — скрипты и Three.js

Все ссылки в собранном сайте относительные, поэтому он работает и на `http://127.0.0.1:8000/demo3d/`, и на `https://USERNAME.github.io/REPO/demo3d/`.

Сборка завершается с ошибкой при повреждённом конфиге, пути вне `demo/`, отсутствующем GLB или файле больше 25 МиБ.

## Локальный запуск

После сборки:

```powershell
python -m http.server 8000 --directory dist
```

Откройте [http://127.0.0.1:8000/demo3d/](http://127.0.0.1:8000/demo3d/). Прямая ссылка на первую локацию: [http://127.0.0.1:8000/demo3d/?scene=location1](http://127.0.0.1:8000/demo3d/?scene=location1). Остановить сервер: Ctrl+C.

Three.js **0.186.0** находится в `web/vendor`; лицензия — `web/vendor/LICENSE`. Исходные файлы получены из [официального npm-пакета Three.js](https://www.npmjs.com/package/three/v/0.186.0).

## Управление

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Вращение вокруг якоря | Левая кнопка мыши и перетаскивание | Перетаскивание одним пальцем |
| Сдвиг якоря вместе с камерой | Правая кнопка мыши и перетаскивание | Движение двумя пальцами |
| Приближение / удаление | Колесо или Shift + левая кнопка и перетаскивание вверх / вниз | Щипок двумя пальцами |
| Стартовый вид | Кнопка «Сбросить вид» | Кнопка «Сбросить вид» |

На компьютере панель справа показывает якорь, yaw / pitch в градусах и дистанцию. Нажатие на число копирует его. Кнопка снизу копирует фрагмент `scenes.json` с четырьмя полями камеры. Буфер обмена в браузере доступен на `localhost` или по HTTPS. На телефоне панель скрыта.

## Модель камеры

- **anchor** — точка в сцене, на которую смотрит камера; вокруг неё происходит орбита.
- **distance** — расстояние от камеры до якоря.
- **yaw** и **pitch** — направление взгляда камеры на якорь (горизонтальный и вертикальный углы в градусах).

Камера всегда смотрит на якорь. Перетаскивание мышью двигает камеру по сфере вокруг этой точки, якорь остаётся в центре кадра. Если сохранённый якорь оказывается в пустоте перед объективом, просмотрщик сажает центр орбиты на поверхность в середине вида, не сдвигая камеру.

## Настройка сцен

Исходный конфиг — `scenes.json` в корне репозитория. После изменений пересоберите сайт и опубликуйте новую версию. Каждая запись содержит обязательные `slug`, `title`, `file` и необязательные параметры камеры:

```json
{
  "slug": "location1",
  "title": "Локация 1",
  "file": "demo/location1.glb",
  "anchor": [0, 1.5, 0],
  "distance": 12,
  "yaw": 35,
  "pitch": 20
}
```

`slug` состоит из строчных латинских букв, цифр и дефисов. Файл должен быть `.glb` внутри каталога `demo/`. Параметр URL `scene` принимает только slug из конфига. Если координаты и дистанция не заданы, просмотрщик берёт центр габаритов основной glTF-сцены и вычисляет дистанцию для обзора. Начальные углы без значений в конфиге: 35° и 20°. Движение посетителя не сохраняется. После настройки вида можно скопировать параметры из панели и вставить их в `scenes.json`, затем пересобрать и опубликовать сайт.

В `location1.glb` записаны две технические glTF-сцены. Просмотрщик показывает только сцену по умолчанию (`scene: 0`). В текущих GLB нет источников света и анимаций, поэтому просмотрщик добавляет нейтральное освещение.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и отправьте в него код вместе с GLB в `demo/`.
2. В репозитории откройте **Settings → Pages** и выберите источник **GitHub Actions**.
3. После push в `main` или `master` workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) соберёт `dist/` и опубликует его.
4. Сайт откроется по адресу `https://USERNAME.github.io/REPO/demo3d/?scene=location1`.

Порядок изменения конфига: исправить `scenes.json` → `git push` → дождаться завершения Actions → обновить страницу в браузере.

Все GLB на статическом сайте публично доступны для скачивания по прямому URL (`demo3d/models/<slug>.glb` относительно корня сайта). Меню ограничивает выбор сцен в интерфейсе, но не закрывает доступ к файлам.

Текущая сборка около 24 МиБ и укладывается в лимит GitHub Pages (1 ГиБ на опубликованный сайт). HTTPS включается автоматически.

## Проверки

```powershell
python -m unittest discover -s tests -v
```

Проверьте обе сцены в настольном браузере и на телефоне: орбиту вокруг якоря, зум, сдвиг правой кнопкой, копирование, кнопку сброса, выбор сцены и прямые ссылки. Размер GLB влияет на время первой загрузки: `location1.glb` около 15 МиБ, `location2-3.glb` около 6 МиБ.
